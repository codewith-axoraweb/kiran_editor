# KIRAN Video Editor & Motion Storyteller Portfolio

A cinematic dark-themed personal portfolio website for KIRAN, a video editor and motion storyteller.

## Features

- Fully responsive design (desktop, tablet, mobile)
- Dark cinematic aesthetic with gold accents
- Sticky navigation with mobile hamburger menu
- Hero section with contact info
- About, Skills, Portfolio, and Contact sections
- Interactive portfolio cards with Bootstrap modals
- Smooth scrolling and subtle animations
- Working phone (`tel:`) and email (`mailto:`) links
- Social media links

## Tech Stack

- HTML5
- CSS3 (custom properties, responsive design)
- Bootstrap 5 (CDN)
- Bootstrap Icons (CDN)
- Vanilla JavaScript

## How to Use

1. Extract the ZIP file.
2. Open the `kiran-portfolio` folder.
3. Double-click `index.html` to open in your browser.

No build tools, npm, or server required. It works as a pure static website.
